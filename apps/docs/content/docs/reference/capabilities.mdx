## Status model

Every capability has two independent answers:

- **Availability**: whether WhatsApp/Baileys can represent the feature.
- **Implementation**: whether whatsappd exposes it as a supported public capability.

Proof also has a level: source inspection, deterministic tests, packed-package replacement, or a bounded real-device observation. A feature can be implemented without yet having the strongest device proof.

The detailed inventory, including every capability ID and its evidence, remains in the repository’s [SDK capability catalogue](https://github.com/AaronAbuUsama/whatsappd/blob/master/docs/architecture/sdk-capabilities.md).
